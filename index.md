# HP-LQC Research Backup

## About this application

HP-LQC Research Backup is a research data backup utility supporting the Holographic-Primordial Loop Quantum Cosmology (HP-LQC) research project.

The application uses Google Drive authorization to back up research notebooks and associated project files from a private GitHub repository to a Google Drive account authorized by the application user.

## Purpose

The application is intended to support:

- Research file preservation
- Automated backups
- Version history and recovery
- Reproducible research documentation

## Data access

The application uses authorized Google Drive access to store and manage research backup files.

Research notebooks and backup contents are not made publicly available through this website.
